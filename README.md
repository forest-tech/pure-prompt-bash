# pure-prompt-bash

Pure-style prompt for Bash.  
Shows SSH host name when connected over SSH.

## Usage

1. Place the prompt script here:

   ```bash
   ~/.config/bash/pure.bash
   ```

2. Source it from `~/.bashrc`:

   ```bash
   source ~/.config/bash/pure.bash
   ```

3. Reload your shell:

   ```bash
   source ~/.bashrc
   ```
